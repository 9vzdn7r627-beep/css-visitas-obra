Para utilizarlo mañana

Importante: este archivo funciona sin IA ni conexión a una nube. En el iPhone, al abrir un HTML descargado, el almacenamiento local puede no mantenerse entre aperturas. Tras cada visita pulsa Guardar copia de visita y conserva el JSON en Archivos. Para una versión fiable instalada y sincronizada necesitamos publicarlo como web privada.

El borrador exportado incluye las fotos seleccionadas, tus notas y datos de la obra. Puedes imprimirlo como PDF desde Safari (Compartir → Imprimir) o enviarlo aquí como archivo HTML. No es un acta definitiva ni está firmada.
